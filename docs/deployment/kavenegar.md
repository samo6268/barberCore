# اتصال کاوه‌نگار به پرنگارین

## الگوی ورود

در پنل کاوه‌نگار یک الگوی اعتبارسنجی با مشخصات زیر بسازید و تا تأیید نهایی آن صبر کنید:

- نام الگو: `parnegarinlogin`
- روش اصلی: پیامک
- روش جایگزین: پیش‌فرض سیستم
- متن:

```text
کد ورود به پرنگارین: %token
این کد را در اختیار دیگران قرار ندهید.
```

نام الگو باید فقط حروف و اعداد انگلیسی و بدون فاصله یا `_` باشد.

## تنظیمات محیط تولید

این مقادیر را در پنل استقرار یا فایل `.env` خصوصی سرور ثبت کنید:

```dotenv
NODE_ENV=production
SMS_PROVIDER=kavenegar
KAVENEGAR_API_KEY=<secret>
KAVENEGAR_OTP_TEMPLATE=parnegarinlogin
```

برای متد `VerifyLookup` نیازی به `KAVENEGAR_SENDER` نیست. این مقدار فقط زمانی لازم است که ارسال پیامک عادی برای اعلان‌های رزرو فعال شود.

کلید API را در Git، تیکت، پیام‌رسان یا لاگ‌های برنامه قرار ندهید.

## آزمون فعال‌سازی

پس از تأیید الگو و ثبت متغیرها، از صفحه ورود درخواست کد کنید. پاسخ API باید موفق باشد و در پنل کاوه‌نگار یک رکورد ارسال برای الگوی `parnegarinlogin` دیده شود.

در محیط توسعه، `SMS_PROVIDER=console` نگه داشته می‌شود و کد ثابت `123456` در لاگ محلی نمایش داده خواهد شد؛ بنابراین تست‌های توسعه اعتبار پیامکی مصرف نمی‌کنند. اگر برای آزمون واقعی، Provider را روی `kavenegar` قرار دهید، کد تصادفی تولید و واقعاً ارسال می‌شود.
