# راهنمای قدیمی اتصال مدل — غیرفعال در نسخه داخلی

این راهنما با نسخه دانش داخلی جایگزین شده است. پچ 0004 را روی نسخه نصب‌شده اعمال کنید؛ به حذف یا Revert پچ 0003 نیاز نیست.

مسیر فعال دیگر به کلید API، نام مدل یا سرویس خارجی نیاز ندارد. متغیرهای قدیمی مدل استفاده نمی‌شوند و اسکریپت `configure-mimo.mjs` دیگر کلیدی درخواست نمی‌کند.

این توضیح مربوط به کنارگذاشتن اتصال خارجی قبلی است. ارتقای جدید، اتصال اختیاری به مدل خودمیزبان از طریق API بومی Ollama دارد؛ مدل خودکار نصب یا فعال نمی‌شود و به OpenAI وابسته نیست.
