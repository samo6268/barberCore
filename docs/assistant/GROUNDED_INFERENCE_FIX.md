# اصلاح تولید مقادیر حدسی و آزمون مدل محلی

## علت اصلاح

در آزمون واقعی سرور، مدل برای «تهران هستم، موهام رو کجا کوتاه کنم؟» خدمت پوست، تاریخ امروز، گزینه اول و حذف فیلتر جنسیت را تولید کرد. اعتبارسنجی تاریخ پاسخ را رد کرد؛ پذیرش این پاسخ برای عبور از خطا صحیح نیست. مدل ۴B نیز به سقف ۳۰ ثانیه رسید و مدل سبک‌تر در برخی آزمون‌ها خروجی نامعتبر داشت. این شواهد کیفیت مطلوب مدل یا آمادگی عمومی آن را تأیید نمی‌کنند.

## رفتار نسخه اصلاح‌شده

- مدل فقط نوع درخواست و شناسه مقاله/فرایند ثبت‌شده را انتخاب می‌کند. شهر، خدمت، تاریخ، جنسیت و شماره گزینه در خروجی مجاز مدل نیستند.
- مقادیر جستجو از متن آخر کاربر و وضعیت معتبر گفتگو می‌آیند. اگر عبارت شناخته نشود، معنای تازه‌ای برای آن حدس زده نمی‌شود. برای موارد مبهم سؤال تکمیلی مطرح می‌شود.
- «موهام رو کجا کوتاه کنم» به کوتاهی نگاشت می‌شود. پوست، امروز و گزینه اول خودکار اضافه نمی‌شوند. انتخاب عددی فقط با اشاره صریح و وجود فهرست گزینه معتبر پذیرفته می‌شود.
- جست‌وجوی صریح مرکز با شهر و خدمت مشخص، و راهنمای لغو نوبت، بدون انتظار برای مدل از ابزار مجاز یا دانش ثبت‌شده پاسخ می‌گیرند. این مسیر میان‌بُر قاعده‌محور است و موفقیت آن به معنی درست‌شدن استنتاج مدل نیست.
- ابهام در شهر، چند خدمت یا نفی انتخاب، محافظه‌کارانه بررسی می‌شود. پشتیبانی کامل زبان طبیعی یا تمام صورت‌بندی‌های نفی ادعا نمی‌شود.
- خروجی مدل کوتاه‌تر است؛ سقف تولید ۹۶ توکن، دو رشته پردازشی و نگه‌داری مدل تا ۱۰ دقیقه تنظیم شده‌اند. تغییر این مقادیر تضمین بهبود سرعت نیست و باید روی سرور آزموده شود.
- وضعیت سلامت دلیل خطای مدل را بدون متن پیام/پاسخ خام تفکیک می‌کند: timeout، transport، invalid-json، invalid-plan و truncated. خروجی قطع‌شده به دلیل محدودیت توکن پذیرفته نمی‌شود.
- کنترل نقش، مالکیت، منابع پاسخ و فقط‌خواندنی‌بودن ابزارها تغییر نکرده‌اند. حالت عمومی rules حفظ می‌شود؛ نصب پچ، مدل را فعال نمی‌کند.

## نصب روی مک و ارسال توسط مالک مخزن

پچ روی نسخه دارای ارتقای 0006 تهیه شده است. ابتدا در ریشه مخزن وضعیت محلی بررسی شود. در صورت تمیزبودن فایل‌های تغییرکرده:

```bash
git switch feat/kavenegar-otp-integration
git pull --ff-only origin feat/kavenegar-otp-integration
git apply --check ~/Downloads/0007-Mimo-Grounded-Inference.patch
git am ~/Downloads/0007-Mimo-Grounded-Inference.patch
npm test --workspace api -- --runInBand src/modules/assistant
npm run build --workspace api
git push origin feat/kavenegar-otp-integration
```

اگر Git یا تست خطا داد، پیش از Push علت بررسی شود. از git add . برای این اصلاح استفاده نشود؛ پچ خودش فقط فایل‌های مربوط را کامیت می‌کند.

## دریافت و ساخت روی سرور

در Terminal مک، اتصال معمول:

```bash
ssh -i ~/.ssh/parnegarin_ed25519 -o IdentitiesOnly=yes -p 3031 deploy@185.116.162.159
```

روی سرور:

```bash
cd /opt/parnegarin
git status --short
git pull --ff-only origin feat/kavenegar-otp-integration
bash scripts/deploy-mimo.sh
```

در خطای Pull توقف کنید. تنظیمات اختصاصی Docker، Redis، پایگاه داده، فایل‌های .env و اسکریپت استقرار قبلاً اصلاح شده‌اند و نباید با reset یا جایگزینی کامل حذف شوند. این پچ این فایل‌ها را عوض نمی‌کند. Migration، seed، تغییر رمز یا نصب Node روی میزبان لازم نیست.

## آزمون مدل واقعی پس از ساخت موفق

نیازی به Paste مجدد کد بلند JavaScript نیست؛ اسکریپت روی سرور موجود است و داخل کانتینر API اجرا می‌شود:

```bash
cd /opt/parnegarin
docker exec -i -e MIMO_TEST_MODEL=qwen3:1.7b barbercore_api node < scripts/benchmark-mimo-local.cjs
```

این آزمون مدل را از قبل بارگذاری می‌کند و چهار سؤال مصنوعی را مستقیماً از مسیر استنتاج مدل می‌فرستد. هیچ ابزار دیتابیس، رزرو، لغو یا پرداختی اجرا نمی‌شود و تنظیمات فرایند اصلی API تغییر نمی‌کند. `valid` فقط اعتبار ساختار پاسخ را نشان می‌دهد؛ `expectedMatched` انتخاب درست در همین نمونه را می‌سنجد. مدت بارگذاری اولیه جدا گزارش می‌شود. سرعت پایین یا موفقیت چند نمونه، به‌تنهایی مبنای فعال‌سازی عمومی نیست؛ سؤال‌های واقعی متنوع و رفتار در بار هم‌زمان باید ارزیابی شوند.

پچ پیش از تحویل روی مدل واقعی سرور اجرا نشده است. زمان بارگذاری اولیه و محدودیت دو هسته پردازنده همچنان باقی می‌مانند. این اصلاح ادعای پاسخ درست به همه سؤال‌ها یا رسیدن به سرعت مشخص ندارد.

## اعتبارسنجی تحویل

کل API: ۲۳ مجموعه و ۱۵۹ تست موفق؛ بیلد API موفق. تست‌ها شامل پاسخ نادرست واقعی گزارش‌شده، عبارت محاوره‌ای کوتاهی، عدم تولید تاریخ/گزینه/جنسیت، نفی و ابهام، دسترسی ابزارها و درخواست HTTP بومی مدل‌اند. اجرای اسکریپت آزمون با پاسخ‌دهنده HTTP آزمایشی محلی بررسی شده است؛ این آزمون معادل اجرای وزن واقعی Qwen نیست. تغییر رابط کاربری یا وابستگی جدید در این پچ وجود ندارد.
